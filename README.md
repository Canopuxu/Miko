# Miko

Miko 是一个 AI 角色聊天项目，支持聊天、QQ 私聊与群聊、人物资料、长期记忆和生活轨迹。模型通过你填写的 API 调用，数据保存在本机。

## 便携版

Windows x64 用户可在[发布页](https://github.com/Canopuxu/Miko/releases/latest)下载便携 ZIP，解压整个压缩包，双击 `Miko.exe`。首次使用在“设置”填写 API 和模型。缺少 WebView2 时，启动器会提供安装入口。

## 源码启动

当前适配 Windows x64 和电脑版 QQ NT。源码启动需要 Python 3.13、Node.js 24、pnpm 11.25.0。

在 PowerShell 中运行：

```powershell
git clone https://github.com/Canopuxu/Miko.git Miko
cd Miko
.\scripts\setup.ps1
.\scripts\start.ps1
```

首次初始化会安装依赖并创建同级的 `MikoLocal` 目录。以后启动只需运行 `.\scripts\start.ps1`。服务就绪后会自动用默认浏览器打开 Miko。使用期间保留命令行窗口，退出时在该窗口按 `Ctrl+C`。

## 首次配置

1. 打开“设置 → 模型与 API”，填写 OpenAI 兼容的 API 基础地址、密钥和模型，点击“测试连接”。修改会自动保存。
2. QQ 聊天、生活生成和记忆整理默认共用“聊天与日常”的配置，可在“分功能设置”中分别指定。记忆整理推荐使用旗舰模型。
3. “记忆检索”中的向量模型和“相关性筛选”中的重排模型均可留空，程序会继续使用本地检索。填写后可进一步增强检索。
4. 在“设定与资料”中修改角色和自己的称呼，添加资料，并调整表达设置。

## 连接 QQ

先登录电脑版 QQ，再到“设置 → QQ 连接”检测并选择账号。连接后，在“QQ 聊天”中添加好友或群聊，并开启接话。连接所需的本地端口和密码由程序管理。

## 记忆与生活

聊天中值得保留的信息会自动整理，可在“记忆”页查看、修改和删除。角色的生活记录和目标在“生活”页管理。

## 数据与备份

配置、聊天、记忆、日志、缓存和备份均保存在 `MikoLocal` 中。便携版位于程序目录内；源码版与源码目录 `Miko` 同级。

在“设置 → 数据与日志”中创建和恢复备份，也可打开数据、日志和备份文件夹。完整备份含私人聊天与 API 密钥，请妥善保管。分享人物设定请使用“设定与资料 → 导入导出”。

便携版：升级时先退出 Miko，将新版解压覆盖原目录，保留 `MikoLocal`。迁移时，一并复制整个 `MikoLocal` 文件夹。

源码版：升级前先创建备份；迁移电脑时，在新目录完成初始化后恢复备份。
