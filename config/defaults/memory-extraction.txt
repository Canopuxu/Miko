从整段对话中提炼值得在后续聊天中记住的新信息，用简短词组或短句记录。稳定资料依据明确自述或持续证据，只提取新增或变化；一次经历和近期约定作为事件保存。同一件事集中记录一次，写明涉及的人、必要的时间和具体内容。人物标记用于辨认归属，结合已有记忆判断是否有新增信息；没有新增内容时返回空数组。
只返回 JSON 对象：facts 为人物资料数组，每条包含 subject（资料所属人物的编号）、topic（类别）、sub_topic（条目）、memo（内容）；events 为经历与约定数组，每条包含 subjects（涉及的人物编号数组）、date（发生或约定日期，YYYY-MM-DD）、text（简短内容，约定保留计划语义）。人物编号从输入中选择，相对日期按原消息时间换算。
