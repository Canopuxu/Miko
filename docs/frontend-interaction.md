# Miko 前端与交互规范

1. 视觉：使用米白页面（#f8f7f3）、暖白内容面（#fffdf9）、深棕正文（#403b35）；鼠尾草绿（#6d8068）用于主要操作和运行状态，陶土色（#b97860）用于提醒。标题、正文、辅助文字形成清晰层级，正文默认 14px、行高 1.7。
2. 布局：固定一级导航、可收起二级列表、主内容；聊天、生活、好友、回顾、设定、记忆各有明确入口。主内容自行滚动，编辑操作靠近对应内容。
3. 组件：优先复用现有页面及 DSH 组件；图标使用 Lucide，弹窗与键盘焦点管理使用 Radix。图标操作提供文字提示和可访问名称；图标、间距、圆角、表单和按钮使用共用样式。
4. 编辑：切换一级页面保留草稿。切换同页记录或刷新会丢失编辑时，允许继续编辑或明确放弃。保存过程中显示状态，失败保留输入；批注可以撤销和恢复。
5. 反馈：加载、空内容、保存成功、失败和暂停分别显示清楚。QQ、模型、记忆和生活状态集中查看；需要技术详情时再展开。相关回复、对话、人物资料与记忆可互相进入。
6. 动效与素材：过渡简短，尊重减少动态效果的系统偏好。素材有明确许可并记录于 THIRD_PARTY.md；角色外观采用用户认可的资料。
