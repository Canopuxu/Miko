# Miko 前端设计与交互规范

## 一、基础视觉规范

1. 字体：界面使用系统无衬线字体，中文优先 Microsoft YaHei，西文优先 Segoe UI；艺术字体用于品牌字标。正文常规字重，标题和重点使用 600 字重。
2. 文字层级：页面标题 24px，区域标题 20px，条目标题 16px，正文与控件文字 14px，辅助信息 12px。标题行高约 1.3，控件文字约 1.5，连续中文正文约 1.7。同类信息在各页使用相同层级。
3. 间距与对齐：采用 4、8、12、16、24、32px 间距档位。同组内容靠近，组与组之间留出更大间距；正文、标签和表单沿共同边线对齐。页面边距随可用宽度调整。
4. 颜色：沿用米白页面 #f8f7f3、暖白内容面 #fffdf9、深棕正文 #403b35、鼠尾草绿 #6d8068 和陶土色 #b97860。辅助正文采用清楚可读的中性色；颜色表示重点、选中和状态，状态同时有文字或图形说明。普通文字与背景对比度至少 4.5:1。
5. 元素：按钮和输入框默认 8px 圆角，卡片 12px，弹窗 16px；边框默认 1px。同类控件保持一致高度、内边距和图标位置；桌面常用控件高度至少 36px，触摸操作区域至少 44px。主要操作使用实色强调，次要操作使用描边或文字。
6. 图标与视觉层次：图标复用 Lucide，常用尺寸为 16px 和 20px，同类图标保持一致线宽。内容分组主要通过排版、间距、底色和细边框表达；浮层使用轻阴影表示层次。图标按钮提供可访问名称，键盘焦点清晰可见。
7. 状态与动效：控件统一呈现默认、悬停、选中、焦点、禁用和加载状态。常规过渡为 140–180ms，并尊重系统减少动态效果的设置。素材许可记录于 THIRD_PARTY.md，角色外观采用用户认可的资料。

## 二、交互约定

1. 切换一级页面保留草稿。切换同页记录或刷新会丢失编辑时，允许继续编辑或明确放弃。保存过程中显示状态，失败保留输入；批注可以撤销和恢复。
2. 加载、空内容、成功、失败和暂停状态清楚可辨。技术详情按需展开；相关回复、对话、人物资料与记忆支持互相进入。
3. 具体导航结构、页面布局和文案方案记录在对应开发规划中；共用规范通过共享样式值和组件落实。
