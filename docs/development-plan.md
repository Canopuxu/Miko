# 开发规划

| 阶段 | 开发任务 | 验收标准 |
| --- | --- | --- |
| 1. 建立开发基线 | 初始化 Miko 源码仓库；建立独立 Python 环境；固定依赖；配置 Miko 专属目录、启动和停止脚本 | 能重复启动、停止；配置和数据均落在 MikoLocal |
| 2. 验证 DSH 整合 | 启动独立 DSH；加载最小 Miko 页面；验证当前模型接口、流式输出、取消任务和后台状态桥接 | 页面能发起一次生成并取消；与你日常使用的 DSH 同时运行 |
| 3. 搭建后台与数据契约 | 定义消息作者、好友状态、生活事件、记忆、批注和转达任务；建立数据库、迁移和接口 | 每条消息能区分你、Miko、好友；事件可以保存、查询和追溯 |
| 4. 迁移 QQ 核心流程 | 复用接收、连续消息合并、旧回复失效、发送确认；实现两分钟等待、连续聊天、本人介入后交还主导权 | 测试小号完整跑通；新消息或你介入时，旧回复不会发出 |
| 5. 接入角色与关系状态 | 加载你提供的设定和本人资料；接入 DSH 分段上下文；保存首次介绍、好友关系和待转达问题 | 同一好友不会反复介绍；“我去问问他”能形成待办并完成转达 |
| 6. 建立记忆系统 | 接入 memU；适配 Memobase 整理流程；加入人物、类别、日期过滤和中文关键词检索；生成可读记忆视图 | 换会话后能找回重要事件；人物归属准确；修正后旧版本可追溯 |
| 7. 加入自主生活 | 保存兴趣、活动、进度和后续计划；定时通过 DSH 推进生活；关联你的已知近况 | 多天活动能延续；不同好友看到同一个 Miko 的生活进展 |
| 8. 完成统一界面与批注 | 完成聊天、今天、好友、回顾、记忆五个入口；按天批注；处理反馈的适用范围与撤销 | 能查看实际回复并修正；反馈在相关场景生效 |
| 9. 第一版联调与发布准备 | 检查重启恢复、任务失败、索引重建、备份恢复和调用记录；整理启动入口 | 关闭页面后后台继续工作；重启后状态恢复；可备份和回退 |
